# Seamaster Scout
## Desktop
`python server.py` (opens your browser at http://localhost:8000).
## Android APK, no Android Studio
1. Put this whole folder in a GitHub repo (keep the `.github` folder).
2. Repo > Actions > Build APK > Run workflow.
3. When it finishes, download `seamaster-scout-apk` from the run page and unzip it for `app-debug.apk`.
4. Install the APK on your phone (allow installs from unknown sources).
